Social Media Intelligence Dashboard: This project is an interactive data visualization dashboard designed to analyze and explore social media usage patterns across 1,000 users and 7 platforms: Pinterest, Facebook, Instagram, TikTok, LinkedIn, Twitter, and Snapchat. 
The dataset comes from Kaggle and includes six important behavioral metrics for each user: daily minutes spent, posts per day, likes per day, and follows per day.
The dashboard starts with a cinematic welcome screen that features a live background image, animated floating orbs, and key stats to set the stage before diving into the data. 
Users then access a completely interactive analytics dashboard created with Chart.js. It presents eight distinct visualizations: a donut chart for platform user share, bar charts for average and total time spent, a radar chart for comparing multiple metrics across platforms, a bubble chart showing post-to-like efficiency, an area line chart illustrating usage time distribution among users, and a detailed drilldown table with inline progress bars and engagement score badges. 
Key findings highlighted by the dashboard show that 38.8% of users spend over 5 hours a day on social media. Facebook leads all platforms in engagement score, even though it does not have the highest session time.
Instagram users make the most posts, averaging 11.3 posts per day.
Twitter has the lowest likes-per-post ratio across all platforms.
The TikTok Paradox, where users post the most but spend the least time, is one of several unique insights featured in this section.
The project was built entirely with HTML, CSS, and JavaScript, with no external frameworks other than Chart.js. It is fully responsive and maintains a consistent dark futuristic design.
